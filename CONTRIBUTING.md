# Contributing to AgroConnect

Thanks for your interest in contributing to AgroConnect.

This repository brings together the original AgroConnect crop-disease system with a production-oriented PWA and full-stack architecture. Contributions in mobile app development, AI/ML pipelines, backend APIs, data management, frontend UX, DevOps, and documentation are welcome.

## Contribution areas
- disease prediction and model evaluation
- RAG and treatment guidance quality
- mobile-first and offline user experience
- multilingual accessibility
- frontend and backend architecture
- deployment and documentation

## Getting started
1. Fork the repository.
2. Clone it to your machine.
3. Create a feature branch.
4. Install the frontend dependencies.
5. Start the Angular app and Java backend.
6. Open a pull request with a clear summary of your work.

## Local setup

### Frontend
```bash
cd frontend
npm install
npm run start
```

### Backend
```bash
cd backend
./mvnw clean install
./mvnw spring-boot:run
```

## Good first tasks
Look for issues labeled:
- `good first issue`
- `help wanted`
- `documentation`
- `enhancement`

## Contribution guidelines
- Keep pull requests focused and easy to review
- Write clear issue descriptions and PR summaries
- Add tests when working on logic, APIs, or platform behavior
- Document any new environment variables or setup steps
- Follow the existing repository coding patterns

A contributor-ready backlog is available in `GITHUB_ISSUES.md`.
