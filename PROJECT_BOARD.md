# AgroConnect Project Board

This file defines the GitHub Project board structure for the AgroConnect-PWA repository.

## Project name
`AgroConnect PWA Roadmap`

## Columns
- Backlog
- Planned
- In Progress
- Review
- Done

## Labels
- `pwa`
- `frontend`
- `backend`
- `ai`
- `rag`
- `ml`
- `mobile`
- `accessibility`
- `performance`
- `documentation`
- `good first issue`
- `help wanted`

## Recommended workflow
1. Add issues to `Backlog` when identified.
2. Move to `Planned` after scoping and prioritization.
3. Move to `In Progress` when development is active.
4. Move to `Review` once the implementation is ready for validation.
5. Mark `Done` after merge and verification.

## Priority areas
- PWA installability and offline support
- Crop disease image capture and upload workflows
- ResNet50 and AI prediction integration
- RAG treatment guidance
- Multilingual support
- Accessibility and low-bandwidth usability
- Deployment and CI/CD setup

## Suggested project priorities
- High priority: PWA, disease workflow, AI integration, treatment guidance
- Medium priority: multilingual support, analytics, security, performance
- Ongoing: documentation, contributor onboarding, deployment automation
