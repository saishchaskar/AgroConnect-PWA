# AgroConnect project documentation

## Original repo context
- Flutter cross-platform app based on Android and web target workflow
- CNN disease prediction using pre-trained ResNet50 embeddings
- RAG-based disease treatment responses
- LLM-generated context-aware recommendations
- Multilingual support for broader accessibility
- Dataset with 450+ crop diseases and pests across India

## Architecture direction
- Angular frontend with shadcn-style design system
- Java Spring Boot backend for API and AI integration
- PWA-first mobile experience
- AI pipeline for disease recognition and recommendations
